AppliesBoth directions, on the same terms
Redemption cap30 redemptions honored by each Shop
TermNov 1, 2026 to Dec 15, 2026
Other termsNone

3. How redemptions are counted

A customer scans a Shop's QR code and receives a one-time code valid 24 hours, usable at the other Shop. A redemption counts only when staff of the honoring Shop confirm the code in ShopMates. A code can be confirmed once.

4. Ending the agreement

The agreement ends on the end date, or when both Shops have reached their caps. Either Shop may end it earlier by written notice through ShopMates. Redemptions already confirmed remain honored.

5. Costs and records

Each Shop bears the cost of the discounts it honors. ShopMates records the confirmed redemptions for each Shop and shows an estimate of discount cost; the estimate is informational and is not an invoice.

6. Plain-English summary

The Shops promote each other for six weeks. Each gives referred customers 10% off, up to 30 customers, and both can see exactly how many each sent. (Summary written by the app from the terms above.)
